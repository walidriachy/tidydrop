# Beginner guide

TidyDrop keeps your `Downloads` folder permanently clean without needing Terminal or manual sorting.

## 1. Install

### On macOS
1. Download [**`TidyDrop.dmg`**](https://github.com/walidriachy/tidydrop/releases/latest/download/TidyDrop.dmg).
2. Double-click the `.dmg` and drag **TidyDrop** into **Applications**.
3. Open **Applications**, **right-click TidyDrop → Open**, and confirm **Open** (needed only the very first time because open-source builds are not Apple-notarized yet).
4. Click **Allow** when macOS asks permission to access your `Downloads` folder.
5. Look for the TidyDrop icon in your top **menu bar** (no Dock icon clutter).

### On Windows
1. Download [**`TidyDrop.Setup.exe`**](https://github.com/walidriachy/tidydrop/releases/latest/download/TidyDrop.Setup.exe).
2. Double-click to run it. If SmartScreen shows *"Windows protected your PC"*, click **More info → Run anyway**.
3. Click **Install** (no admin password needed).
4. Look for the TidyDrop icon in your **system tray** next to the clock (click `^` if hidden).

## 2. Try Preview mode first (recommended)

If you want to watch what TidyDrop would do before moving any files:

1. Click the TidyDrop icon in your menu bar / system tray.
2. Turn on **Preview mode**.
3. Open **Settings → Activity log** to see every planned rename and destination folder.
4. Once you are happy with the results, turn off **Preview mode** to let TidyDrop organize automatically.

## 3. Undo any move

Changed your mind about a file?
- Click the tray icon → **Undo** to reverse the most recent move, or
- Open **Settings → Activity log** to review recent moves and undo them cleanly.

## 4. Pause or uninstall anytime

- **Pause temporarily:** Click the tray icon → **Pause**.
- **Uninstall on macOS:** Quit TidyDrop from the menu bar and drag `TidyDrop.app` from Applications to Trash.
- **Uninstall on Windows:** Open **Settings → Apps → Installed apps → TidyDrop → Uninstall**.
