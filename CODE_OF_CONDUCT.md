# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

* Be kind and patient. Many users and contributors here are beginners, and questions are welcome.
* Disagree with ideas, not people.
* No harassment, personal attacks, or sharing other people's private information.

Report unacceptable behaviour privately to the maintainers using GitHub's **Report content** option or a private security advisory. Reports are handled confidentially, and maintainers may remove content or contributors that break these rules.
